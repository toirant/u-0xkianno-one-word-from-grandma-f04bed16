## The word

**Al**

The single word a grandma would text about AI — short, warm, and
familiar, like naming an old friend at the table.

## How it works

Run it exactly as the grader does:

```sh
node main.ts
```

`main.ts` writes the word to `/output/entry.txt` (UTF-8 text, 2
characters, not only whitespace — inside the 1–30 character gate). It
creates the output directory when it is missing and clears only the
files inside it, never the directory itself.
